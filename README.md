# Prestamo

El repositorio está organizado en dos proyectos independientes:

```text
prestamo/
├── backend/   # API REST con Node.js y Express
└── frontend/  # Aplicación Flutter
```

## Backend

```powershell
cd backend
npm install
npm run dev
```

## Frontend

```powershell
cd frontend
flutter pub get
flutter run
```

Consulta los README de cada proyecto para más detalles de configuración.
