Esta política explica qué datos recoge la aplicación móvil Préstamo Amigo, para qué se usan y cómo puedes ejercer tus derechos. Al usar la app, aceptas esta política.

1. Qué es Préstamo Amigo

Préstamo Amigo es una aplicación móvil para solicitar préstamos, consultar cuotas, registrar pagos (por ejemplo Nequi o pago personal), recibir notificaciones y contactar soporte. Existe un rol de usuario y un rol de administrador.

2. Datos que recogemos

Según el uso de la app, podemos tratar:

  • Datos de cuenta: nombre, apellido, correo electrónico, teléfono, cédula y contraseña (almacenada de forma cifrada/hash).
  • Datos de perfil: foto de perfil, si decides subirla.
  • Datos de préstamos y pagos: monto solicitado, número de cuotas, motivo, método de desembolso, número Nequi cuando aplica, estado de solicitudes, cuotas y pagos.
  • Comprobantes: imágenes de comprobantes de pago que el usuario sube para validación.
  • Mensajes de soporte: conversaciones con el asistente o con el administrador.
  • Notificaciones: avisos sobre solicitudes, aprobaciones, pagos u otros eventos de la app.
  • Datos técnicos básicos: identificadores necesarios para el funcionamiento del servicio (por ejemplo token de sesión) y, si están activas, referencias de instalación para notificaciones push.

3. Para qué usamos los datos

  • Crear y verificar la cuenta (incluido el envío de códigos al correo).
  • Autenticar el acceso y proteger la sesión.
  • Gestionar solicitudes de préstamo, desembolsos, cuotas y pagos.
  • Permitir la validación de pagos por parte del administrador.
  • Enviar notificaciones y mensajes relacionados con el servicio.
  • Brindar soporte dentro de la aplicación.
  • Cumplir requisitos de seguridad y prevenir usos indebidos.

No vendemos datos personales a terceros con fines comerciales.

4. Base del tratamiento y voluntariedad

Los datos se tratan para prestar el servicio que solicitas al registrarte y usar la app. Algunos datos son necesarios para crear la cuenta o procesar un préstamo; si no los proporcionas, esas funciones pueden no estar disponibles.

5. Con quién compartimos información

Podemos usar proveedores de infraestructura y servicio que tratan datos solo para operar la app, por ejemplo:

  • Alojamiento del backend y base de datos.
  • Envío de correos (códigos de verificación o recuperación).
  • Almacenamiento de imágenes (foto de perfil o comprobantes).
  • Servicios de notificaciones push, si están habilitados.

También puede verse información necesaria por el administrador de la aplicación para aprobar solicitudes, validar pagos o brindar soporte. No compartimos datos con anunciantes ajenos al servicio.

6. Almacenamiento y seguridad

Aplicamos medidas razonables de seguridad, como el uso de contraseñas cifradas/hash, acceso autenticado mediante token y comunicación con el servidor por canales protegidos cuando se usa HTTPS. Ningún sistema es 100% libre de riesgo, pero trabajamos para reducir accesos no autorizados.

7. Conservación de los datos

Conservamos la información mientras la cuenta esté activa y sea necesaria para el servicio, el historial de préstamos/pagos o exigencias de respaldo del proyecto. Si eliminas tu cuenta desde la app, se eliminarán los datos asociados en la medida técnicamente posible. Algunos registros pueden conservarse temporalmente por seguridad o integridad del sistema.

8. Derechos de las personas usuarias

Puedes solicitar acceso, actualización o eliminación de tus datos, y cerrar o eliminar tu cuenta desde la propia aplicación cuando esa función esté disponible. También puedes escribir al contacto indicado más abajo para dudas sobre privacidad.

9. Menores de edad

La aplicación no está dirigida a menores de 14 años. Si detectamos una cuenta creada sin la autorización correspondiente, podrá eliminarse.

10. Cambios a esta política

Podemos actualizar esta política para reflejar cambios en la app o en la normativa. La fecha de actualización aparecerá al inicio del documento. El uso continuado de la app después de un cambio implica que conoces la versión vigente publicada en esta URL.
